# reallyme-eudi-rp-registration

Strict EUDI Wallet Relying Party registration and credential profiles.

Parses and validates EUDI Wallet Relying Party registration data and credential profiles. Trust inputs and application authorization policy remain explicit caller responsibilities.

Select the `native` or `wasm` feature for the intended Rust provider lane.
Neither provider lane is enabled by default.
