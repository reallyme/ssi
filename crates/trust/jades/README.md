# reallyme-trust-jades

ETSI TS 119 182-1 JAdES Baseline validation for ReallyMe trust decisions.

Applies JAdES Baseline policy to an already authenticated compact-JWS result. JOSE parsing and signature verification belong to the JOSE implementation; document profile policy belongs to the consuming application.

Select the `native` or `wasm` feature for the intended Rust provider lane.
Neither provider lane is enabled by default.
