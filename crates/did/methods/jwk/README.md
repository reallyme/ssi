# reallyme-did-method-jwk

ReallyMe did:jwk method support.

Provides the `did:jwk` method implementation for the ReallyMe DID stack. The composed DID API is available separately as `reallyme-did-api`.

Select the `native` or `wasm` feature for the intended Rust provider lane.
The default feature selects `native`; disable default features when selecting `wasm`.
